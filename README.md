# 📊 Task 7 – Basic Sales Summary using MySQL and Python

This project was completed as part of my **Data Analyst Internship** tasks.

---

## 📌 Objective

To build a simple sales summary system by connecting Python with a MySQL database, executing SQL queries, analyzing sales data, and visualizing the insights using bar charts.

---

## 🛠 Tools & Technologies Used

- **MySQL** – For creating and managing the sales database  
- **Python** – Core programming language used for data interaction and analysis  
- **pandas** – To convert SQL query results into structured DataFrames  
- **matplotlib** – To create clear and informative bar charts  
- **Visual Studio Code (VS Code)** – Preferred code editor for development

---

## ⭐ Key Features

- 🔗 **Database Integration**: Connects Python to a MySQL database using `mysql.connector`  
- 📊 **SQL-Based Aggregation**: Summarizes quantity and revenue per product using SQL `GROUP BY`  
- 📋 **Data Handling**: Loads results into a pandas DataFrame for clean data manipulation  
- 📈 **Visualization**: Generates a bar chart using `matplotlib` to display revenue per product  
- 💾 **Export Capability**: Saves the chart as an image (`sales_chart.png`)  
- ✅ **Clean Resource Management**: Closes database connections after execution to ensure stability
